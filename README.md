# Ezequiel Calderon — Portfolio

Welcome to the repository for my personal portfolio. This site is a minimalist, content-focused showcase of my work at the intersection of product delivery, design, engineering, and public-sector policy.

**Live Site:** [ezequielcalderon.com](https://www.ezequielcalderon.com/)

## The Focus
The design of this site prioritizes clarity and high-signal information. Moving away from traditional complex front-end flourishes, I focused on a "content-first" architecture to highlight my work with Fortune 500 companies and my strategic leadership in public affairs.

## Tech Stack
This iteration represents a complete rebuild from my original Bootstrap site, moving toward a modern, component-based developer experience:

* **Framework:** [Astro](https://astro.build/) (for performance and optimized builds)
* **Styling:** [Tailwind CSS](https://tailwindcss.com/) (for utility-first, responsive design)
* **Deployment:** GitHub Pages
* **Icons:** Lucide Icons / SVG

## Features
- **Responsive Architecture:** Fully optimized for mobile, tablet, and desktop viewing.
- **Metric-Driven Experience:** Focuses on proven results and quantitative impact from roles at AKQA Leap, PwC, and Praxent.
- **Project Governance:** Includes deep dives into product management, governance, and legislative policy projects.

## History & Evolution
This repo originally hosted a site built with jQuery and Bootstrap v4. I rebuilt the site on Astro and Tailwind.
